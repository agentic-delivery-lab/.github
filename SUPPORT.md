# Support

## Find an answer

Start with the affected repository's README and documentation. Search existing
issues and pull requests for related questions, known limitations, and
workarounds. Check the repository's contribution and security policies before
asking for help.

## Ask a question

If the documentation does not answer your question, open a GitHub issue in the
affected repository. Choose the most relevant issue form, or use the enabled
blank-issue option when no form fits. Describe what you are trying to do,
include the relevant version and environment, and provide a small safe example
that demonstrates the problem.

Remove passwords, API keys, private keys, access tokens, personal data, and
other sensitive information from logs, screenshots, and configuration before
posting them. Do not paste a suspected vulnerability into a public issue.

## Security concerns

Security concerns must be reported privately through the affected repository's
Security tab as described in [`SECURITY.md`](SECURITY.md).
