# Agentic Delivery Lab

Agentic Delivery Lab maintains an issue-based delivery lifecycle for its
repositories. Public contribution defaults live in this repository; the
architecture authority, delivery control plane, reusable primitives, and
developer distribution are maintained in their own repositories.

Issues remain the durable work record. Projects, Actions, agents, and other
automation are projections or execution surfaces and must link back to the
originating work item.

Start with the target repository's README and contribution guidance. Do not
put credentials, runtime state, or mutable delivery state in this repository.
